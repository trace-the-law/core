# Trace the Law brand assets

The primary mark represents three versions of a public record connected by one
visible evidence trail. It is project branding, not an official or government
seal.

## Files

| File | Use |
|---|---|
| `trace-the-law-icon.png` | Primary rounded-square app and website icon |
| `trace-the-law-mark.png` | Standalone transparent mark without the square |
| `trace-the-law-favicon.png` | Simplified micro-size master for browser icons |
| `favicon.ico` | Browser favicon containing 16, 32, and 48 px sizes |
| `favicon-16.png` | 16 px browser icon |
| `favicon-32.png` | 32 px browser icon |
| `favicon-48.png` | 48 px browser icon |
| `apple-touch-icon.png` | 180 px Apple touch icon |
| `icon-192.png` | 192 px web app icon |
| `icon-512.png` | 512 px web app icon |

## Palette

- Civic navy: `#17324D`
- Archival ivory: `#F3EBDD`
- Oxidized copper: `#B85C3F`

Keep the icon's proportions and colors intact. Use the standalone mark only on
backgrounds that preserve clear contrast around all three ivory layers. Do not
combine the mark with government names, seals, flags, or insignia in a way that
could imply official status or endorsement.
